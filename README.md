## 🚀 Getting Started

### Prerequisites

- Python 3.8+
- Node.js (if the frontend needs it)

### Installation

```bash
git clone https://github.com/Kashiish134/HealthCare-Chatbot.git
cd HealthCare-Chatbot
pip install -r requirements.txt
```

### Run the project

```bash
python [main file].py
```

> ✏️ Replace `[main file]` with the entry file of the project, and add any API keys to a `.env` file.
